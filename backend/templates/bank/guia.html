📖 Guía del Módulo Bancario

Aprende a usar el módulo de banco paso a paso. Cada ejemplo incluye las acciones a realizar y el asiento contable que se genera automáticamente.

Regla de oro: Los movimientos de banco nunca se crean manualmente. El sistema los genera automáticamente cuando registras una venta, compra, gasto o reserva.

Contenidos

  1. Crear cuenta bancaria
  2. Venta de contado
  3. Reserva (arras/señal)
  4. Cobro fraccionado (plazos)
  5. Conciliación bancaria
  6. Regularización anual de existencias
Ejemplo 1

Crear cuenta bancaria

Antes de usar el módulo bancario, necesitas al menos una cuenta configurada. Esta cuenta se vincula a una subcuenta del PGC grupo 572 (Banco).

Pasos:

  1. Ve a 🏦 Banco en el sidebar
  2. Haz clic en "+ Nueva Cuenta"
  3. Rellena el formulario:
    • Nombre: BBVA Empresa
    • IBAN: ES91 2100 0418 4502 0005 1332
    • SWIFT: BBVAESMMXXX (opcional)
    • Cuenta contable: 572 - Banco
  4. Haz clic en "Crear Cuenta"

Resultado: Aparece en el dashboard con saldo €0.00. Los movimientos aparecerán automáticamente cuando registres ventas, compras o gastos.

Asiento contable: Ninguno. Solo se crea la cuenta contable vinculada.

Ejemplo 2

Venta de contado

Cuando vendes un vehículo de contado, el sistema genera automáticamente: el movimiento bancario (INGRESO), el asiento contable REBU, y baja el inventario.

Datos del ejemplo:

Vehículo: VW Golf VIII — Precio compra subasta: €8.000

Coste reparaciones: €2.500 → Coste total: €10.500

Precio de venta: €14.000 (transferencia bancaria)

Pasos:

  1. Ve a 🚗 Vehículos → verifica que el vehículo está en estado ACONDICIONADO
  2. Ve a 💰 Ventas → "+ Nueva Venta"
  3. Selecciona el vehículo, rellena datos del cliente
  4. Método de pago: TRANSFERENCIA
  5. Precio de venta: 14000
  6. Haz clic en "Registrar Venta"

Lo que hace el sistema automáticamente:

📊 Asiento contable (REBU)

CuentaDebeHaber
572 Banco€14.000
600 Compras mercaderías€10.500
700 Ventas mercaderías€2.975,21
471 HP IVA repercutido REBU€624,79
310 Mercaderías€10.500

Margen = 14.000 - 10.500 = €3.500
Base REBU = 3.500 / 1.21 = €2.975,21
IVA REBU = 2.975,21 × 21% = €624,79

🏦 Movimiento bancario

Tipo: INGRESO

Importe: €14.000

Concepto: "Cobro cliente Juan García"

Conciliado: No

El movimiento queda pendiente de conciliar con el extracto bancario real.

Tip: Si el método de pago es FINANCIADO, el Debe va a cuenta 430 (Clientes) en lugar de 572 (Banco). El cobro se registra después con los plazos.

Ejemplo 3

Reserva (arras/señal)

Un cliente deja una señal de €500 para apartar un vehículo. El sistema crea un anticipo con IVA y un movimiento bancario. Al convertir en venta, el anticipo se descuenta.

Datos del ejemplo:

Vehículo: BMW Serie 3 — Precio venta: €18.000

Cliente: María López

Señal/Reserva: €500

Paso 1 — Crear la reserva:

  1. Ve a 🔖 Reservas → "+ Nueva Reserva"
  2. Selecciona el vehículo, rellena datos del cliente
  3. Importe: 500
  4. Haz clic en "Crear Reserva"

📊 Asiento contable (Anticipo)

CuentaDebeHaber
572 Banco€500,00
438 Anticipos Clientes€413,22
477 HP IVA Repercutido€86,78

Base = 500 / 1.21 = €413,22
IVA = 413,22 × 21% = €86,78

🏦 Movimiento bancario

Tipo: INGRESO

Importe: €500

Concepto: "Reserva/Señal BMW Serie 3 - María López"

Paso 2 — Convertir en venta:

  1. Ve a 🔖 Reservas → haz clic en la reserva
  2. Haz clic en "Convertir en Venta"
  3. Se abre el formulario de venta con el vehículo pre-seleccionado
  4. Registra la venta normalmente

Al convertir: El asiento de venta REBU se genera por el precio completo (€18.000). El anticipo de €500 queda registrado en cuenta 438 y se compensa contablemente cuando el cliente paga el resto (€17.500).

Opciones de cancelación:

  • Devolver señal: Crea un EGRESO de €500 (el dinero vuelve al cliente)
  • Penalizar: La S.L. retiene la señal. No se crea movimiento de egreso.
Ejemplo 4

Cobro fraccionado (plazos)

El cliente paga un vehículo de €12.000 en 3 plazos de €4.000. Cada plazo genera su propio movimiento bancario y asiento contable.

Paso 1 — Definir los plazos:

  1. Registra la venta normalmente (método: FINANCIADO o DIRECTA)
  2. Ve a 💰 Ventas → selecciona la venta
  3. Haz clic en "Cobros" (o ve a /erp/ventas/{id}/cobros/)
  4. Haz clic en "+ Añadir Plazo" 3 veces:
Plazo Vencimiento Financiación Importe
#115/08/2026Directa S.L.€4.000
#215/09/2026Directa S.L.€4.000
#315/10/2026Directa S.L.€4.000

Paso 2 — Recibir un plazo:

  1. En la lista de cobros, haz clic en "Marcar recibido" del plazo #1
  2. El sistema crea automáticamente el movimiento bancario y el asiento

📊 Asiento — Plazo directo (S.L. financia)

CuentaDebeHaber
572 Banco€4.000
430 Clientes€4.000

📊 Asiento — Financiación externa (con comisión)

CuentaDebeHaber
572 Banco (neto)€3.800
626 Comisiones bancarias€200
430 Clientes€4.000

La financiera ingresa €3.800 y cobra €200 de comisión.

Tip: Cuando el total cobrado supera el precio de venta, la venta se marca automáticamente como PAGADA.

Ejemplo 5

Conciliación bancaria

Sube el extracto de tu banco (Excel o CSV) y el sistema busca automáticamente los movimientos que coinciden con los del ERP.

Formato del archivo Excel:

Ejemplo de extracto bancario (BBVA, Santander, etc.):

FechaConceptoTipoImporte
2026-07-15Transferencia Juan GarcíaINGRESO14000
2026-07-16Pago factura proveedorEGRESO-2500
2026-07-18Señal María LópezINGRESO500

Pasos:

  1. Ve a 🏦 Banco → "Conciliación Bancaria"
  2. Selecciona la cuenta bancaria
  3. Sube el archivo Excel o CSV
  4. Haz clic en "Procesar Extracto"
  5. El sistema muestra los resultados del matching:
    • ✓ Verde: coincidencia automática (mismo importe, fecha ±2 días)
    • ⏳ Amarillo: sin coincidencia (revisar manualmente)
  6. Marca los movimientos a conciliar
  7. Haz clic en "Conciliación automática"

Algoritmo de matching:

1. Mismo tipo: INGRESO ↔ INGRESO, EGRESO ↔ EGRESO

2. Mismo importe: coincidencia exacta en valor absoluto

3. Fecha ±2 días: compensa el desfase de fecha valor del banco

4. Concepto: similitud de texto (SequenceMatcher) como desempate

Tip: Las columnas del Excel se mapean automáticamente. El sistema busca columnas con nombres como "fecha", "concepto", "importe", "tipo". No importa el orden ni si hay columnas extra.

Ejemplo 6

Regularización anual de existencias

Al cierre de ejercicio (31 de diciembre), el sistema ajusta el valor del inventario de vehículos no vendidos para el balance de la S.L.

Ejecutar el comando:

cd backend

python manage.py regularizar_existencias --ano 2025

Resultado esperado:

Supongamos que a 31/12/2025 hay 3 vehículos sin vender:

  • VW Golf VIII — coste_inicial: €8.000
  • BMW Serie 3 — coste_inicial: €12.000
  • Audi A4 — coste_inicial: €9.500

Valor total del stock: €29.500

📊 Asiento de regularización

CuentaDebeHaber
300 Existencias (Mercaderías)€29.500
611 Variación de existencias€29.500

Este asiento es idempotente: si ya existe uno para ese año, se omite.

Nota fiscal: La cuenta 300 refleja el valor del stock en el balance. La cuenta 611 ajusta la variación de existencias en la cuenta de resultados. Este asiento se ejecuta una sola vez al cierre de cada año.
